# Specs contrôle formats

Le fichier uploadé est probablement non identifié à ce stade.
Determiner son format et en vérifier la cohérence.
Extraire de ce format les infos utile pour déplacer le fichier
Déplacer le fichier au bon endroit


## messages

- `SUBJECT_03_IN` : message consommé en situation nominale
- `SUBJECT_03_OUT` : message produit en situation nominale
- `SUBJECT_03_ERR` : message produit en cas d'erreur


## stockage

Stockage local du fichier en cours de contrôle.
